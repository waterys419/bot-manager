Controls & offline play

Arrows = D-pad · X = B · Z = A · Enter = Start · Shift = Select. Start pauses; Select changes sound. Use the emulator's Controls menu to remap your pad. Touch controls appear on phones.

This is the same .sfc cartridge running in a local Snes9x emulator. Saves stay in this browser. The emulator menu can export saves and save states.
